# Самый простой способ подключить бота (без своего сервера)

Всё уже собрано в один процесс: `app.js` одновременно раздаёт приложение, API и бота. Нужен только бесплатный хостинг, который умеет постоянно держать запущенным Node.js-процесс — например **Render.com**.

## Шаг 1. Получи токен бота
В Telegram напиши **@BotFather** → `/newbot` → следуй инструкциям → он даст токен вида `123456:ABC-...`. Сохрани его.

## Шаг 2. Залей эту папку на GitHub
Самый простой способ — создать новый репозиторий на github.com и загрузить в него содержимое папки `telegram-mini-app/` целиком (через веб-интерфейс GitHub можно просто перетащить файлы, без командной строки).

## Шаг 3. Разверни на Render.com
1. Зайди на render.com → **New → Web Service** → подключи тот самый GitHub-репозиторий.
2. Build Command: `npm install`
3. Start Command: `npm start`
4. В разделе **Environment** добавь переменные:
   - `BOT_TOKEN` = токен из шага 1
   - `PUBLIC_URL` = адрес, который Render покажет тебе после деплоя (вида `https://weight-goal-app.onrender.com`) — его можно вписать сразу после первого деплоя и передеплоить (Render сделает это сам при сохранении переменной).
5. Нажми Deploy. Через пару минут сервис поднимется — и бот, и API, и сама страница уже работают на одном адресе.

## Шаг 4. Подключи адрес к боту
Снова напиши **@BotFather** → `/newapp` (или `/setmenubutton`) → выбери своего бота → вставь тот же `PUBLIC_URL` в качестве адреса Mini App.

## Шаг 5. Проверка
Открой бота в Telegram → `/start` → нажми «Открыть приложение» — должно появиться твоё настоящее имя из Telegram, а данные будут сохраняться в базе на Render между заходами.

---

**Дальше** можно не трогать код вообще — просто пользоваться. Если Render "усыпляет" бесплатный сервис после простоя, первое открытие после паузы может занять 20–30 секунд — это нормально для бесплатного тарифа.
